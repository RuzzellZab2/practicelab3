# Концепт: Ревьюер

Где живет:
- Пользователь (роль reviewer)

Что это:
- Пользователь платформы в роли reviewer: проверяет работы учеников, выносит вердикт (принято / на доработку) и оставляет комментарий — оставляет ревью.

Синонимы:
- Reviewer
- Проверяющий
- Рецензент

Не путать с:
- Пользователь
  - Почему можно спутать: в речи «ревьюер проверил работу» и «пользователь проверил работу» звучат одинаково.
  - Почему различаем: пользователь — учётная запись человека; ревьюер — его роль в системе. 
- Ревью
  - Почему можно спутать: «ревьюер» и «ревью» звучат похоже и оба связаны с проверкой работ.
  - Почему различаем: ревьюер — актор (кто проверяет), ревью — результат проверки (что остаётся после проверки: вердикт + комментарий).
- Ученик
  - Почему можно спутать: и ученик, и ревьюер — роли пользователя на платформе.
  - Почему различаем: ученик выполняет и сдаёт работы, ревьюер проверяет и выносит вердикт по работам.

Вложенные концепты:
- (нет)

Категории:
- Ревьюер курса
  - Что это: ревьюер, который проверяет работы учеников в рамках конкретного курса.
  - Пример: Мария проверяет работы учеников группы 9А по курсу «Python».

Примеры:
- Пример: ревьюер Мария открыла работу ученика, оставила комментарий и поставила статус «Работа принята» — это ревьюер курса.
- Антипример: бот, который автоматически проверяет тесты, — это не ревьюер, а системный процесс.

Рамки (границы модели ценности):
- Ревьюер — роль, а не отдельная учётная запись:
  - out_of_scope: отдельный аккаунт или сущность «ревьюер» в отрыве от пользователя.
  - why: ревьюер — фасет пользователя; отдельная сущность дублирует данные и усложняет смену ролей.


# Value Cases

## Value Case: Ревьюер — проверить работу
<!-- Входит в v2 - да -->

### Обстоятельства
- Работа на ревью

### Возможные результаты
- Ревью с вердиктом «принято»
  - ревьюер видит вердикт "принято" и комментарий к работе
- Ревью с вердиктом «на доработку»
  - ревьюер видит вердикт "на доработку" и комментарий к работе

### Что понадобится
- Веб-сервис — увидеть работу ученика
- Веб-сервис — увидеть сохраненный черновик ревью
- Веб-сервис — увидеть сохраненный вердикт "принято"
- Веб-сервис — увидеть сохраненный вердикт "на доработку"

## Value Case: Ревьюер — посмотреть историю ревью по работе
<!-- Входит в v2 - да -->

### Обстоятельства
- Работа имеет хотя бы одно ревью

### Возможные результаты
- Список всех ревью
  - ревьюер видит вердикты и комментарии по версиям работы

### Что понадобится
- Веб-сервис - увидеть отфильтрованный/отсортированный список ревью по дате отправки на ревью


## Value Case: Ревьюер — посмотреть список работ на ревью
<!-- Входит в v2 - да -->

### Обстоятельства
- Ревьюер назначен на курс

### Возможные результаты
- Список работ на ревью
  - ревьюер видит работы, ожидающие проверки
- Пустой список
  - ревьюер видит уведомление "Нет работ на ревью"

### Что понадобится
- Веб-сервис — увидеть список работ на ревью
- Веб-сервис - увидеть отфильтрованный/отсортированный список работ: по дате отправки на ревью, по имени ученика, по уроку, по курсу
