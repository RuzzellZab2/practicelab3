# Концепт: Ученик

Где живет:
- Пользователь (роль student)

Что это:
- Пользователь платформы в роли student: проходит курсы, выполняет задания и отправляет работы на ревью.

Синонимы:
- Student
- Студент
- Обучающийся

Не путать с:
- Пользователь
  - Почему можно спутать: в речи «ученик сдал работу» и «пользователь сдал работу» звучат одинаково.
  - Почему различаем: пользователь — учётная запись человека; ученик — его роль в системе. Один пользователь может быть учеником в одном курсе и ревьюером в другом.
- Работа ученика
  - Почему можно спутать: «ученик» и «работа ученика» оба связаны с обучением.
  - Почему различаем: ученик — актор (кто выполняет и сдаёт), работа — артефакт (что он сдаёт).
- Прогресс ученика
  - Почему можно спутать: «ученик» и «прогресс ученика» оба относятся к прохождению курса.
  - Почему различаем: ученик — субъект, прогресс — состояние его прохождения курса.

Вложенные концепты:
- (нет)

Категории:
- Ученик курса
  - Что это: ученик, записанный на конкретный курс и проходящий его.
  - Пример: Иван записался на курс «Python» и проходит уроки.
- Ученик группы
  - Что это: ученик, входящий в группу, которой открыт общий доступ к курсу.
  - Пример: Иван добавлен в группу «9А», которой администратор открыл доступ к курсу.

Примеры:
- Пример: ученик Иван отправил работу на ревью через веб-сервис — это ученик.
- Антипример: ревьюер, который проверяет работы, — это не ученик, а другая роль пользователя.

Рамки (границы модели ценности):
- Ученик — роль, а не отдельная учётная запись:
  - out_of_scope: отдельный аккаунт или сущность «ученик» в отрыве от пользователя.
  - why: ученик — фасет пользователя; отдельная сущность дублирует данные и усложняет смену ролей.

# Value Cases

## Value Case: Ученик — отправить практическую работу на ревью

### Обстоятельства
- Сохраненный черновик работы

### Возможные результаты
- Работа на ревью
  - уведомление "Работа на ревью"
- Неотправленная работа
  - уведомление об ошибке отправки


### Что понадобится
- Веб-сервис — увидеть уведомление "Работа на ревью"
- Веб-сервис — увидеть уведомление об ошибке отправки


## Value Case: Ученик — выполнить практическую работу

### Обстоятельства
- Работа не начата
- Работа "На доработке"

### Возможные результаты
- Сохраненный черновик
  - ученик видит черновик практической работы

### Что понадобится
- Веб-сервис — получить инструменты для выполнения работы


## Value Case: Ученик — посмотреть прогресс по курсу

### Обстоятельства
- Начатый курс

### Возможные результаты
- Сформированный прогресс
  - Ученик видит прогресс

### Что понадобится
- Веб-сервис — увидеть прогресс


## Value Case: Ученик — пройти шаг

### Обстоятельства
- Начатый шаг

### Возможные результаты
- Пройденный шаг
  - ученик видит уведомление "Шаг пройден"
- Непройденный шаг
  - ученик видит уведомление "Шаг не пройден"

### Что понадобится
- Веб-сервис - увидеть инструменты для выполнения шага c чеклистом самопроверки
- Веб-сервис - увидеть инструменты для выполнения шага с иллюстрацией
- Веб-сервис - увидеть инструменты для выполнения шага с видео
- Веб-сервис - увидеть инструменты для выполнения шага с квизом
- Веб-сервис - увидеть инструменты для выполнения шага с интерактивным заданием
- Веб-сервис — увидеть уведомление "Шаг пройден"
- Веб-сервис — увидеть уведомление "Шаг не пройден"
