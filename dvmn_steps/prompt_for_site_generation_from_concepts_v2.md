Сгенерируй proof-of-concept одностраничного веб-приложения на чистом HTML/CSS/JS (без фреймворков, без сборщиков) с in-memory моками вместо бэкенда и БД.

Что есть на входе:

- Репозиторий с файлами спецификации: concepts/ — описание сущностей предметной области, value-cases/ — карточки сценариев использования в формате Product Flow.
- Каждая карточка имеет пометку "входит в v2" или нет. Реализовать нужно те `value cases`, где стоит отметка "входит в v2".

Что должно быть на выходе:

- Полнофункциональный PoC, который проходит по всем mvp-сценариям без бэкенда.
- Все данные живут в JS-объектах. Любое действие должно мутировать эти объекты и ощущаться как реальное — с задержкой, с валидацией, с обратной связью (alert'ы, обновление UI).
- Навигация — мягкая, без перезагрузки страницы. JS-логика подгружается динамически для каждой "страницы" (разные HTML-шаблоны с привязанными скриптами).

Чего НЕ должно быть:

- Никакого реального бэкенда, БД, авторизации, API-запросов. Только моки.
- Никаких фреймворков, сборщиков, npm. Всё работает из файловой системы через HTTP-сервер.

Стиль:

- Аккуратный минималистичный CSS (достаточно для наглядности, но без излишеств).
- Все тексты на русском языке.
- Понятная обратная связь на каждое действие пользователя.
