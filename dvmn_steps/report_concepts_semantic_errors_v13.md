# Отчёт v13: смысловые ошибки в концептах

Проверка карточек концептов (`concepts/`) после очередного раунда исправлений. Закомментированные блоки удалены, TODO-комментарий убран. Смысловых ошибок в активном содержимом не найдено — модель согласована.

## Найденные замечания

### 1. Путь доступа «Курс для группы» не описан value case (полнота)

Модель доступа теперь согласована, но закрыта сценарием только наполовину:

- Самозапись покрыта value case «Ученик — записаться на курс» (`student.md`), с обстоятельством «Не курс для группы».
- Путь «Курс для группы» — действия администратора («создать группу», «добавить ученика в группу», «открыть доступ к курсу») — **не имеет ни одного value case**.

Соответственно у ролей нет сценариев:

- **Администратор** (`admin.md`): создать группу, добавить ученика, открыть доступ к курсу.
- **Владелец** (`owner.md`): назначить Администратора.

Это единственная незакрытая часть модели — `admin.md` и `owner.md` не содержат секции «Value Cases».

### 2. Категория «Ученик группы» без поддерживающего сценария (следствие п.1)

`student.md:28-30` — «Ученик группы» («ученик, которого Администратор записал в группу») — корректна как категория, но сценария «Администратор записывает ученика в группу» нет (см. п.1).

## Что изменилось в этом раунде

- Удалены 5 закомментированных блоков (`course.md`, `lesson.md`, `student_work.md`, `reviewer.md`, `user.md`).
- Убран TODO-комментарий в `user.md`.

- Замечания: 2 (оба сводятся к полноте value cases для ролей Администратор/Владелец) — низкоприоритетные.
