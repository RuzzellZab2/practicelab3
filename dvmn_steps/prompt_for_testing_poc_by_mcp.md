Проверь сайт на соответствие спецификации.

Для каждого `value case` в пометкой "Входит в v2" проверь:
- Совпадает ли актор из карточки с тем, от чьего лица выполняется действие
- Выполнены ли обстоятельства (предусловия) из карточки перед началом сценария
- Каждый результат и каждый акцептор из карточки проявляется в интерфейсе (текст, статус, уведомление, изменение состояния)
- Если в карточке есть негативный результат ("не удалось", ошибка) — он тоже проверен
