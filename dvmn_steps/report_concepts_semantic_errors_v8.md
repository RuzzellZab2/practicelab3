# Отчёт v8: смысловые ошибки в концептах

Проверка карточек концептов (`concepts/`) после очередного раунда исправлений. Ошибки из v7 в основном устранены; критичных противоречий в активном содержимом нет. Ниже — оставшиеся замечания.

## Найденные замечания

### 1. Соотношение «Курс для группы» и «Опубликованный курс» (низкий приоритет, осталось из v7)

- `course.md:33-35` («Опубликованный курс») + value case «Ученик — записаться на курс» — ученик **сам записывается** на опубликованный курс.
- `course.md:30-32` («Курс для группы») + `admin.md`/`group.md` — доступ **выдаёт администратор** группе.

Модель по-прежнему не определяет, как соотносятся два механизма доступа: может ли ученик сам записаться на курс «для группы», или там доступ только через администратора. Стоит уточнить, является ли «Курс для группы» подвидом «Опубликованного курса» или отдельной осью.

### 2. Закомментированные «остатки» (чистка, не смысловое)

После правок остались закомментированные блоки — теперь ещё и в `course.md:22-29` («Начатый курс»/«Завершенный курс»), плюс ранее: `lesson.md:35-42`, `student_work.md:46-50`, `reviewer.md:32-36`, `user.md:35-52`. Если это осознанный «след правок» — ок; иначе мёртвый контент лучше удалять, а не комментировать.

### 3. У «Администратора» и «Владельца» нет value cases (полнота)

- `admin.md` и `owner.md` не содержат секции «Value Cases», хотя описывают действия (открыть доступ, создать группу, назначить администратора).
- `user.md` TODO упоминает только «…становится … Администратором»; про Владельца не сказано.

Это не противоречие, а незакрытая часть модели: действия этих ролей не описаны сценариями.

## Что исправлено в этом раунде

- `course.md` — категории «Начатый курс»/«Завершенный курс» перенесены из «Курса».
- `student_progress.md` — жизненный цикл («Начатый курс»/«Завершённый курс») теперь живёт здесь, а не в «Курсе» (закомментированный блок из v7 заменён на корректный).

## Сводка

- Критичных смысловых ошибок в активном содержимом: нет.
- Замечания: 3 (соотношение механизмов доступа; закомментированные остатки; отсутствие value cases у admin/owner).
