# Отчёт v12: смысловые ошибки в концептах

Проверка карточек концептов (`concepts/`) после очередного раунда исправлений. Смысловых ошибок в активном содержимом не найдено — модель сошлась. Остаются только замечания по полноте и чистке.

## Найденные замечания

### 1. Нет value cases у ролей «Администратор» и «Владелец» (полнота)

Действия этих ролей описаны в карточках, но не закрыты сценариями:

- Администратор: создать группу, добавить ученика в группу, открыть доступ к курсу (в т.ч. к «Курсу для группы»).
- Владелец: назначить Администратора.

В `admin.md` и `owner.md` нет секции «Value Cases» (в отличие от остальных ролей). Из-за этого путь доступа «курс для группы → администратор открывает доступ группе» остаётся не описанным сценарием (в отличие от самозаписи, покрытой value case «Ученик — записаться на курс»).

### 2. Закомментированные «остатки» (чистка, не смысловое)

По-прежнему остаются закомментированные блоки: `course.md:22-29`, `lesson.md:35-42`, `student_work.md:46-50`, `reviewer.md:32-36`, `user.md:35-52`. Если это осознанный «след правок» — ок; иначе мёртвый контент лучше удалить.

## Что исправлено в этом раунде

- `student.md:30` — из примера «Ученик группы» убрано «и имеет доступ к курсу» (снята неявная связь «членство в группе → доступ к курсу»).

## Сводка

- Критичных смысловых ошибок: нет.
- Замечания: 2 (полнота value cases для admin/owner; закомментированные остатки) — низкоприоритетные.
