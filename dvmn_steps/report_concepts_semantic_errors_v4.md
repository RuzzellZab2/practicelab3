# Отчёт v4: смысловые ошибки в концептах

Проверка карточек концептов (`concepts/`) после очередного раунда исправлений. Большинство ошибок из v3 устранено; осталась одна и появился один низкоприоритетный нюанс.

## Осталось (не исправлено)

### 1. `concepts/student.md:35` — «урок с дедлайном» противоречит «дедлайну курса»

- Категория «Должник» (`:29`) — «просрочил **дедлайн курса**» (курс-уровень, согласовано с `course.md`, `course_author.md`, `group.md`).
- Пример внизу (`:35`) всё ещё — «не сдал вовремя **урок с дедлайном**».

Внутренняя нестыковка внутри одного файла: модель переведена на дедлайн курса, а пример остался урок-уровневым.

## Низкий приоритет

### 2. `concepts/admin.md:7` vs `concepts/owner.md:7` — пересечение полномочий по ролям

- `admin.md:7` — администратор «управляет пользователями и **ролями**».
- `owner.md:7` — владелец «**назначает Администраторов**».
- При этом `admin.md:23` («Не путать с Владелец») — «владелец **назначает администраторов**».

Формулировка «управляет ролями» у администратора потенциально пересекается с назначением администраторов владельцем. Стоит уточнить, кто именно управляет какими ролями (в т.ч. ролью `admin`).

## Что исправлено в этом раунде (для истории)

- `course.md:33` — убран «одобрение Администратором»; пример теперь согласован с «опубликован Автором курса».
- `course_author.md:86-97` — value case переведён с «дедлайн урока» на «дедлайн курса».
- `student.md:66-67` — убрано противоречивое обстоятельство «Курс без дедлайна».
- `reviewer.md:39` — пример исправлен с «ревьюер урока» на «ревьюер курса».
- `user.md` — секция «Категории» закомментирована (снято дублирование ролей со «Вложенными концептами»).
