Твоя задача — проверить все `value cases` для роли <название роли> на соответствие чеклисту симптомов из файла `value-case-checklist.md`.

## Требования к проверке

- Каждый `value case` проверяется по каждому симптому чеклиста.
- Для каждого найденного симптома указать конкретное место в карточке (поле, фрагмент текста).

## Формат отчёта

В отчёт попадают только `value cases`, в которых найдены симптомы. Если с карточкой всё в порядке — она не упоминается.

```markdown
# Отчёт проверки `value cases` по чеклисту симптомов

## `Value cases` с замечаниями

### <название `value case`>

<симптом> — <где именно в карточке>
  <как исправить>

<симптом> — <где именно в карточке>
  <как исправить>

---

### <название `value case`>
...

---

## Сводка
- Проверено `value cases`: <число>
- Без замечаний: <число>
- С замечаниями: <число>
- Всего найдено симптомов: <число>
