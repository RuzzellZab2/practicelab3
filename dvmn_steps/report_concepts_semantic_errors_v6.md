# Отчёт v6: смысловые ошибки в концептах

Проверка карточек концептов (`concepts/`) после очередного раунда исправлений. Ошибки из v5 исправлены; найдены новые (преимущественно низкоприоритетные) нестыковки.

## Найденные ошибки

### 1. Дублирование/рассогласование жизненного цикла прогресса

Одно и то же состояние прохождения описано в двух карточках с разной гранулярностью:

- `course.md:22-27` — категории «**Начатый курс**», «**Завершенный курс**» (2 состояния).
- `student_progress.md:26-34` — категории «**Курс начат**», «**Курс в процессе**», «**Курс завершён**» (3 состояния).

«Начатый курс» (`course.md`) по определению («ученик начал проходить курс») перекрывает сразу два состояния прогресса — «Курс начат» и «Курс в процессе». А «Завершенный курс» дублирует «Курс завершён». Жизненный цикл стоит описать в одном месте (например, в «Прогресс ученика»), а в «Курсе» либо сослаться, либо не дублировать.

### 2. `concepts/admin.md:7` — назначение роли «Администратор» всё ещё неоднозначно (низкий приоритет)

- Добавлено уточнение: «Администратор не может **снять** роль Администратор с себя или другого человека».
- Но про **назначение** роли `admin` не сказано: осталось «управляет ролями (кроме Владелец)», что формально может включать и назначение администраторов — тогда это пересекается с `owner.md` («владелец назначает Администраторов»).

Стоит явно зафиксировать, кто может **назначать** роль `admin` (по логике — только Владелец).

### 3. `concepts/student_progress.md:7` — ссылка на несмоделированную сущность (низкий приоритет)

- «…сколько **работ с интерактивным заданием** проверено…».
- В карточке «Работа ученика» (`student_work.md`) нет такой категории: там только «Работа на ревью / Принятая / На доработке / Черновик». «Интерактивное задание» — это тип **шага** (`step.md`), а не тип работы.

Либо добавить «работу с интерактивным заданием» в модель, либо убрать её из описания прогресса.

## Замечание (не смысловое)

### 4. `concepts/course.md:29` — грамматика

- «…в котором **доступ настроены** для конкретной группы…» → «**доступ настроен**» (после переименования «Курс с группами» → «Курс для группы»).

## Что исправлено в этом раунде

- `course.md` — «Курс с группами» переименован в «Курс для группы», убрано «расписание» (согласовано с `group.md`).
- `student_progress.md` — убраны технические имена полей `current_lesson_id`, `completed_at`, `NULL`.
- `admin.md` — добавлено «не может снять роль Администратор».

## Сводка

- Найдено: 3 смысловых (1 — дублирование прогресса; 2 — назначение роли admin; 3 — «работа с интерактивным заданием»), 1 грамматическое замечание.
