# Фичи платформ с позиции Администратора обучения

## 1. edX (Open edX + edX Insights)

**Админ-фичи:**

| Фича | Описание |
|---|---|
| Аналитика по зачислениям (Enrollment) | Количество записанных, активность записи, демография (возраст, образование, пол), география |
| Аналитика вовлечённости (Engagement) | Вовлечённость с контентом и видео: сколько студентов смотрят/читают/взаимодействуют |
| Аналитика успеваемости (Performance) | Производительность по заданиям: graded и ungraded — какие задачи даются хуже всего, распределение ответов |
| Индивидуальный профиль ученика (Learners) | Поиск конкретного ученика, его активность по задачам и видео с таймлайном |
| Экспорт данных | Выгрузка данных по ученикам и их успеваемости |
| Управление сертификатами | Выдача/отзыв сертификатов о прохождении |
| Настройка оценивания (Grading Policy) | Веса заданий, проходной балл, политика дедлайнов, grace period |
| Аудит и верификация | Разделение потоков audit / verified / credit-eligible |
| Интеграция LTI | Подключение внешних инструментов и их отслеживание |
| Группы (Cohorts) | Разделение студентов на когорты с разным контентом |
| Bulk email / уведомления | Массовая рассылка по ученикам курса |

**Хотелки администратора обучения (edX):**

| Хотелка | Описание |
|---|---|
| Dashboard по прогрессу в реальном времени | Не раз в сутки, а live-данные по сдаче работ |
| Heatmap «узких мест» курса | Какие шаги/задания бросают чаще всего, где отсев |
| Автоматические триггеры | Уведомить преподавателя, если >30% не сдали работу после дедлайна |
| Сравнение когорт между собой | cohort A vs cohort B по успеваемости |
| История изменений успеваемости | Тренды студента по неделям (регресс/прогресс) |
| AI-подсказки для админа | «Этим студентам нужна помощь» на основе паттернов |

## 2. Stepik

**Админ-фичи:**

| Фича | Описание |
|---|---|
| Статистика курса | Общая: количество учеников, проходимость, рейтинг |
| Статистика по шагам | Сколько учеников дошло до шага, решило, не решило |
| Детальная статистика по задачам | Распределение ответов, время решения, количество попыток |
| Управление ревьюерами | Назначение проверяющих на работы учеников |
| Очередь на ревью | Список работ, ожидающих проверки, с фильтрами и сортировкой |
| Комментарии преподавателя | Возможность писать фидбек прямо к работе ученика |
| Отложенная публикация | Планирование выхода уроков/курсов по дате |
| Сертификаты | Автоматическая выдача сертификатов при выполнении условий |
| Группы учеников | Создание групп и назначение кураторов |
| Экспорт (CSV/Excel) | Выгрузка оценок, прогресса, активности |
| Дедлайны | Настройка сроков сдачи и "мягких"/"жёстких" дедлайнов |
| Прокторинг | Контроль честности при сдаче (внешние сервисы) |
| A/B тестирование | Показ разных версий шага разным группам |

**Хотелки администратора обучения (Stepik):**

| Хотелка | Описание |
|---|---|
| Аналитика удержания | Retention-кривая: сколько остаётся к n-ому уроку |
| Dashboard с пирогами и фильтрами | Визуальный дашборд, а не таблицы |
| Автоматическое распределение ревью | Ревьюер назначается по нагрузке, а не вручную |
| SLA по проверке работ | Метрика «сколько времени работа ждёт проверки» |
| Отчёт по преподавателям | Кто проверил сколько работ, среднее время проверки |
| Уведомления о «застрявших» студентах | Те, кто не сдаёт работу >7 дней — алерт админу |

## 3. Khan Academy

**Админ-фичи (для школ/дистриктов):**

| Фича | Описание |
|---|---|
| Teacher dashboard | Учитель видит прогресс класса по навыкам и заданиям |
| Mastery data | Данные по освоению навыков (Mastery levels: attempted, practiced, mastered) |
| Class summary | Сводка по классу: сколько учеников выполнили, сколько практикуют, сколько отстают |
| Student-level report | Детальный профиль ученика: какие навыки освоил, где застрял |
| Assignment management | Создание и назначение заданий (practice, quiz, unit test) целому классу |
| Рекомендации по навыкам | Система подсказывает, какие навыки подтянуть классу/ученику |
| District Insights (для дистриктов) | Сводка по школам: использование платформы, прогресс, охват |
| Roster integration | Интеграция со школьными системами (Clever, Google Classroom) |
| Professional development | Материалы для повышения квалификации учителей |
| Khanmigo for teachers (AI) | Генерация lesson plans, rubrics, exit tickets, grouping |
| Progress alerts | Оповещения, если ученик — в зоне риска |

**Хотелки администратора обучения (Khan Academy):**

| Хотелка | Описание |
|---|---|
| Настраиваемый учебный план (custom curriculum path) | Не только готовые курсы, но и своя последовательность тем |
| Сквозная аналитика по дистрикту | Сравнение школ между собой по progress и mastery |
| Автоматическая группировка учеников | AI-группировка по уровню mastery для дифференцированного обучения |
| Формирование отчётов для родителей | PDF/email с прогрессом ребёнка за период |
| Интеграция с LMS (Canvas, Moodle) | Передача оценок из Khan Academy в школьную LMS |
| Настройка проходных критериев | Порог mastery для зачёта темы (не "3 из 5", а кастомно) |
| Массовое добавление учеников через CSV | Упрощение онбординга для больших дистриктов |
