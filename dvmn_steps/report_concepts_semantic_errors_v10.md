# Отчёт v10: смысловые ошибки в концептах

Проверка карточек концептов (`concepts/`) после очередного раунда исправлений. Противоречие доступа из v9 устранено, но правка `course.md` внесла новое противоречие про дедлайн.

## Найденные ошибки

### 1. `concepts/course.md:31` — дедлайн на уровне группы противоречит карточке Группы

- `course.md:31` («Курс для группы»): «курс, в котором доступ и **дедлайн настроен для конкретной группы**».
- `group.md:34`: «Даты доступа и **дедлайны настраиваются на уровне курса, а не на уровне группы**».

Прямое противоречие: карточка курса утверждает, что дедлайн задаётся «для группы», а карточка группы явно относит дедлайны к уровню курса, а не группы.

### 2. `concepts/course.md` — «Курс для группы» смешивает две оси

«Курс для группы» (`:31`) теперь включает и «доступ», и «дедлайн», пересекаясь с категорией «Курс с дедлайном» (`:39-40`, «курс, для которого установлен дедлайн»). Две категории начали описывать дедлайн одновременно. Также пример `:32` не соответствует определению (про дедлайн в примере ничего нет).

### 3. Грамматика

`concepts/course.md:31` — «доступ и дедлайн **настроен**» → «доступ и дедлайн **настроены**».

### 4. `concepts/student.md:28-30` — «Ученик группы» без подкрепляющего сценария (низкий приоритет)

- «Ученик группы» — «ученик, которого Администратор записал в группу», пример «записан в группу „9А“ и **имеет доступ к курсу**».
- Пример неявно утверждает «членство в группе → доступ к курсу», но сценария «Администратор добавляет ученика в группу / открывает доступ группе» нет. Связь «Ученик группы» ↔ «Ученик курса» по-прежнему не определена.

## Что исправлено в этом раунде

- `group.md:8` — удалена противоречивая строка «доступ только через Администратора» (и опечатка «какоми-либо»).
- `student.md:53` — в value case «записаться на курс» добавлено обстоятельство «Не курс для группы» (самозапись ограничена не-групповыми курсами).

## Сводка

- Найдено: 3 смысловых (дедлайн на уровне группы; пересечение «Курс для группы» и «Курс с дедлайном»; «Ученик группы» без сценария), 1 грамматика.
