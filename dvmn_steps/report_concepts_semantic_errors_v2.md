# Отчёт v2: смысловые ошибки в концептах

Повторная проверка карточек концептов (`concepts/`) после исправлений. Часть ошибок из первого отчёта устранена, часть осталась, часть правок создала новые нестыковки.

## Осталось (не доисправлено)

### 1. `concepts/course.md:33` — пример «Опубликованный курс» противоречит исправленной строке 32

- Строка 32 исправлена: «курс, который опубликован **Автором курса**».
- Пример (`:33`) всё ещё описывает старый поток: «автор … сделал **запрос Администратору на публикацию** … после **одобрения Администратором**».

Противоречит и строке 32, и value case «Автор курса — опубликовать курс».

### 2. `concepts/course_author.md:24` — «кто назначает ревьюера» не доисправлено внутри файла

- Строка 7 и value case «Автор курса — назначить ревьюера на курс» — назначает автор.
- Строка 24 всё ещё: «администратор — за доступ: … **назначение ревьюеров**».

`user.md:43` и `reviewer.md:34` исправлены, эта строка — нет.

### 3. `concepts/group.md:33` — не тронуто

- «дедлайны настраиваются на уровне **курса или урока** (через `lesson_group_deadlines`)».

Содержит и утечку технического поля (`lesson_group_deadlines`), и неоднозначность «курс/урок».

## Новое противоречие (после переноса дедлайна на уровень курса)

- `student.md:35` — пример «не сдал вовремя **урок с дедлайном**».
