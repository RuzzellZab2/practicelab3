# Отчёт v3: смысловые ошибки в концептах

Проверка карточек концептов (`concepts/`) после очередного раунда исправлений и добавления карточек `admin.md` и `owner.md`.

## Осталось (не доисправлено до конца)

### 1. `concepts/course.md:33` — «одобрение Администратором» противоречит публикации автором

- Строка 32: «курс, который опубликован **Автором курса**».
- Пример (`:33`): «…после **одобрения Администратором** пользователи могут записаться».

Шаг «одобрение публикации Администратором» отсутствует и в value case «Автор курса — опубликовать курс», и в карточке `admin.md` (там про доступ, а не про одобрение публикации).

### 2. Дедлайн: value case всё ещё урок-уровневый

- `course.md:37` («Курс с дедлайном»), `group.md:33` («на уровне курса»), `student.md:29` («Должник» — «дедлайн курса») — всё переведено на уровень курса.
- Но value case «Автор курса — установить **дедлайн урока**» (`course_author.md:86-97`) остался урок-уровневым: обстоятельство «Урок без дедлайна», результат «Урок с дедлайном», акцептор «на уроке», «к уроку».

### 3. `concepts/student.md:35` — внутренняя нестыковка

- Категория «Должник» (`:29`) — «просрочил **дедлайн курса**».
- Пример внизу (`:35`) — «не сдал вовремя **урок с дедлайном**».

## Новое (внесено последними правками)

### 4. `concepts/student.md:66-67` — взаимоисключающие обстоятельства

В value case «Ученик — выполнить практическую работу» перечислены одновременно:

- «**Курс не просрочен**» (есть дедлайн, который ещё не прошёл);
- «**Курс без дедлайна**» (дедлайна нет вовсе).

«Курс без дедлайна» не может быть «просрочен» — условия противоречат друг другу, одно из них лишнее.

### 5. `concepts/reviewer.md:39` — ссылка на удалённую категорию

- Категория «Ревьюер урока» закомментирована (`:32-36`).
- Пример `:39` всё ещё: «…это **ревьюер урока**».

## Низкий приоритет (не тронуто из прошлых отчётов)

### 6. `concepts/user.md` — дублирование ролей в двух секциях

Роли «Ученик / Ревьюер / Автор курса / Администратор / Владелец» перечислены одновременно и во «**Вложенных концептах**» (`:29-33`), и в «**Категориях**» (`:36-50`).

## Сводка

- Осталось неисправленным: 3 (одобрение публикации; дедлайн урока в value case; пример «Должника»)
- Новое после правок: 2 (взаимоисключающие обстоятельства; ссылка на удалённую категорию)
- Низкий приоритет: 1 (дублирование ролей в user.md)
