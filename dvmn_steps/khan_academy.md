Берём платформу khanacademy.org. Какие возможности платформа даёт автору урока?
Перечисли списком. Минимум 10 пунктов, лучше больше.
Автор урока отвечает за контент, но не за монетизацию/маркетинг.

Ответ:

Возможности Khan Academy для автора урока (16 пунктов):

1. Создание видеоуроков — запись через встроенную студию с наложением скринкаста/слайдов
2. Текстовые статьи (Articles) — написание теории с форматированием, вставкой изображений, таблиц, формул LaTeX
3. Задачи с автопроверкой (Exercises) — числовой ввод, multiple choice, сортировка, drag-and-drop, free response
4. Поддержка формул — встроенный редактор LaTeX для математических и научных выражений
5. Пошаговая система подсказок (Hints) — последовательные подсказки, открывающиеся по запросу ученика
6. Подсказки-видео — к задаче можно прикрепить короткое видео-объяснение
7. Условное открытие контента — следующая тема открывается после набора определённого количества баллов (Mastery-based progression)
8. Skill / Mastery System — автор задаёт, какие навыки проверяет каждый урок; отслеживание прогресса до полного освоения
9. Группировка в course/unit/lesson — иерархия: Course → Unit → Lesson → Exercise/Article/Video
10. Настройка числа попыток — разрешить или запретить «покажи ответ» в зависимости от сложности
11. Привязка к учебным стандартам — тегирование заданий по Common Core, NGSS и др.
12. Интерактивные виджеты (PJS, iframe) — вставка JavaScript-симуляций прямо в урок
13. Coaching / статистика тьютора — автор видит по каждому ученику: освоенные навыки, проблемные места
14. Статистика по задачам — % правильных ответов, распределение ошибок, количество подсказок, время на задачу
15. Локализация контента — создание контента на разных языках с авто-выбором версии по языку ученика
16. Обсуждения под уроком — ученики задают вопросы, автор отвечает

Статусная модель для описания управления доступом (курсы и уроки):

Статусы Курса (для ученика):
1. Недоступен — ученик не добавлен / курс ещё не начался
2. Доступен — ученик может зайти и начать обучение
3. В процессе — хотя бы один урок начат
4. Завершён — все обязательные уроки пройдены (Mastery достигнута)
5. Просрочен — дедлайн курса истёк, доступ закрыт

Статусы Урока (для ученика):
1. Заблокирован — предыдущий урок не пройден / не набран нужный уровень Mastery / дедлайн не настал
2. Доступен — ученик может начать, но ещё не начал
3. В процессе — ученик открыл, выполняет задания
4. На проверке — работа отправлена (если применимо, Khan Academy обычно без ревью)
5. Пройден — ученик набрал проходной балл / достиг Mastery
6. Провален — дедлайн истёк / превышен лимит попыток / Mastery не достигнута за отведённое время

| Хотелка | Обстоятельства | Связь с концептами |
|---|---|---|
| Записать видеообъяснение темы | Ученикам нужен визуальный разбор материала перед практикой | **Шаг** — видео как единица «прочитать/посмотреть»; **Урок** — контейнер видеошагов |
| Написать статью с теорией | Конспект или дополнительное чтение для закрепления | **Шаг** — единица «прочитать»; **Урок** — набор статей и упражнений |
| Составить задачу с автопроверкой | Ученик должен потренироваться и сразу узнать результат | **Шаг** — ученик «отвечает, выполняет»; результат проверки определяет прогресс по **Уроку** |
| Добавить пошаговые подсказки к задаче | Ученик застревает и просит помощь, но не хочет сразу смотреть ответ | **Шаг** — подсказки помогают выполнить шаг без прямого ответа |
| Прикрепить видео-подсказку | Текстовой подсказки недостаточно, нужно показать решение | **Шаг** — альтернативная форма помощи на шаге |
| Настроить условное открытие по Mastery | Ученик должен освоить текущую тему, прежде чем перейти к следующей | **Урок** (пройденный/текущий) — статус mastery урока определяет доступ к следующему; **Курс** — последовательное прохождение |
| Назначить навыки (Skills) на урок | Платформа должна отслеживать, какие конкретно умения ученик освоил | **Урок** — навыки проверяются внутри урока; **Курс** — набор навыков по всему курсу |
| Построить иерархию course/unit/lesson | Большой курс нужно разбить на разделы для навигации | **Курс** — корень иерархии; **Урок** — единица внутри курса; появляется промежуточный «unit» |
| Настроить лимит попыток на задачу | Ученик не должен бесконечно угадывать ответ | **Шаг** — лимит попыток регулирует выполнение шага |
| Привязать задачи к учебным стандартам | Школам нужно отчитываться, какие стандарты покрыты | **Шаг** — тег стандарта на шаге; **Курс** — отчёт по покрытию стандартов |
| Встроить симуляцию/виджет в урок | Абстрактное понятие нужно показать в динамике (график, схема) | **Шаг** — интерактивный виджет как формат шага |
| Посмотреть статистику тьютора по ученику | Автор/учитель хочет видеть, кто из учеников отстаёт | **Урок** — прогресс по уроку на каждого ученика; **Курс** — сводка по курсу; **Шаг** — проблемы на конкретных шагах |
| Создать контент на нескольких языках | Курс нужен в разных странах / для разных языковых групп | **Шаг** — локализованный контент шага; **Урок** — язык выбирается под ученика |
